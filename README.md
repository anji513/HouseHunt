Features:
- Admin, Owner and Renter roles
- JWT Authentication
- MongoDB Atlas
- Property Listings
- Booking Management
- Search & Filters
- Responsive UI

Folder Structure:
client/
server/
README.md
LICENSE

Installation:
git clone https://github.com/anji513/HouseHunt.git
cd HouseHunt
npm install

Run:
Frontend: npm run dev
Backend: npm start (or npm run dev)

Environment Variables:
PORT
MONGO_URI
JWT_SECRET
